# Google Ads Account Structure

## What this skill does

Rebuilds or designs account structure so budget follows intent and value - brand, generic, competitor and remarketing separated, each with its own target.

## Inputs to collect

- Offer list with margins and conversion values
- Current account structure export (if any)
- Conversion tracking status and values

## Workflow

1. **Segment by intent first** - Separate brand, high-intent generic, research-stage and competitor traffic. These have different values and must never share a budget or a target.
2. **Group keywords tightly** - Ad groups around a single intent theme (5-15 close variants), so ad copy and landing pages can match precisely.
3. **Set budget by value** - Allocate by margin-weighted conversion value and impression share headroom, not by habit or equal splits.
4. **Wire conversion values** - Confirm primary conversions carry real values (lead quality tiers or revenue). Smart bidding on junk conversions optimises for junk.
5. **Document the naming system** - Consistent naming: market | intent | match/theme | target. Anyone should read the account like a map.

## Deliverable

- Structure diagram: campaigns, ad groups, budgets, targets
- Naming convention document
- Rebuild plan with phased migration steps (if restructuring)

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Budget share by intent tier | Should match the value each tier produces |
| Search impression share (brand vs generic) | Brand near 100%; generic judged against CAC |
| Cost per conversion by campaign | Variance across intent tiers is expected and managed, not averaged away |

## Quality checklist

- [ ] No mixed-intent campaigns sharing one target
- [ ] Conversion tracking verified with a test conversion
- [ ] Structure documented so another operator can run it

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Ad policy compliance: no misleading claims, no prohibited content, no trademark abuse. Ads must promise only what the landing page delivers.
- Never advertise results, prices or offers the business cannot honour today.
