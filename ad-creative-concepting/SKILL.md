# Ad Creative Concepting

## What this skill does

Generates a disciplined set of distinct concepts per campaign, each rooted in a different persuasion angle, so testing compares ideas - not fonts.

## Inputs to collect

- Creative brief with proposition and insight
- Proof library and claims register
- Winning and losing creative history (with results)

## Workflow

1. **Work the angle grid** - For the proposition, draft one concept per angle: pain/agitation, outcome, mechanism, proof/data, comparison, testimonial/story, offer. Seven angles minimum before selecting.
2. **Write the first frame first** - For each concept, the opening line/image that stops the scroll, written before anything else. If the first frame is weak, the concept is weak regardless of its body.
3. **Script the full unit** - Headline, body/visual sequence, proof moment, CTA - complete enough to produce without further invention by the designer.
4. **Score and select** - Score concepts on proposition clarity, insight truth, proof strength and producibility. Select a test set that spans angles, not three versions of the favourite.
5. **Brief production with variants** - Each selected concept ships with its test variants planned (hook alternatives) and the hypothesis it carries into the test matrix.

## Deliverable

- Concept set with angle labels and first frames
- Scoring sheet and selected test set
- Production briefs with variant plans

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Angle-level win rate across campaigns | Learns which persuasion routes this audience believes |
| Concept-to-winner rate | Share of produced concepts that beat the control |
| Production cycle time from concept to live | Concept clarity speeds everything downstream |

## Quality checklist

- [ ] Concepts span genuinely different angles
- [ ] Every claim in every concept is in the claims register
- [ ] First frames written for every concept before selection

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Brand claims obey the same proof rules as performance claims. Aspiration is fine; fabrication is not.
