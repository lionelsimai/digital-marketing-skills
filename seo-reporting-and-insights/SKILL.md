# SEO Reporting and Insights

## What this skill does

Converts Search Console and analytics data into a monthly narrative a stakeholder can act on: what changed, why, and the next three moves.

## Inputs to collect

- Search Console and GA4 access or exports
- Keyword map and target cluster list
- Change log of SEO work shipped that period

## Workflow

1. **Report by intent, not totals** - Break clicks and visibility into transactional, commercial and informational clusters. Totals hide the money movement.
2. **Name winners and losers** - Top 5 gaining and losing pages with a hypothesis for each, cross-checked against the change log and any algorithm-update timing.
3. **Connect to outcomes** - Show organic leads/sales and assisted conversions next to traffic. Traffic up, outcomes flat is a finding, not a success.
4. **Grade last month's actions** - For each shipped change: expected effect, actual effect, verdict (keep, extend, revert). This is where the learning lives.
5. **Commit next actions** - End with exactly 3 prioritised actions, owners and the metric each should move.

## Deliverable

- Monthly SEO report: intent breakdown, winners/losers, outcomes
- Action grading table for shipped work
- Next 3 actions with owners and target metrics

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Transactional cluster clicks | The SEO number closest to revenue |
| Forecast vs actual visibility | Improves planning honesty over time |
| Action completion rate | Reports that don't change the work are decoration |

## Quality checklist

- [ ] Every movement has a hypothesis, labelled as such
- [ ] No vanity metrics reported without an outcome metric beside them
- [ ] Algorithm-update speculation flagged as unconfirmed

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- White-hat only: no purchased links, link schemes, PBNs, keyword stuffing, cloaking or scraped/spun content. Earn coverage and links with assets worth citing.
