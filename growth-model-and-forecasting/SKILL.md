# Growth Model and Forecasting

## What this skill does

Replaces hope-based targets with a driver tree anyone can challenge: change one assumption and see what the quarter looks like.

## Inputs to collect

- Current funnel numbers by stage for the last 2-3 periods
- Channel-level traffic and cost data
- Planned budget and any known seasonality

## Workflow

1. **Build the driver tree** - Revenue = traffic x conversion rate x close rate x average value x repeat rate. Fill every node with actuals, flagging estimates.
2. **Set base, stretch and downside cases** - Three scenarios with explicit assumptions each. The downside case is a planning tool, not pessimism.
3. **Run sensitivity** - Vary each driver +/-20% to find which lever moves revenue most. That lever becomes the quarter's top project.
4. **Tie budget to the model** - Convert required traffic into channel spend using current CPCs and conversion rates. If the budget cannot buy the target, say so now.
5. **Set the review rhythm** - Monthly: replace assumptions with actuals, re-forecast, and record which assumption was wrong and why.

## Deliverable

- Driver-tree model with actuals and flagged estimates
- Three scenarios with assumptions listed
- Sensitivity ranking: the lever that matters most

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Forecast accuracy | Actual vs forecast at 30/60/90 days; aim to narrow the error each quarter |
| Assumption error log | Which drivers you consistently over- or under-estimate |
| Required vs available budget ratio | Targets that need 2x the budget get renegotiated, not wished for |

## Quality checklist

- [ ] Every number in the model is an actual or a flagged estimate
- [ ] Downside case has a pre-agreed response
- [ ] Model fits on one page a non-analyst can read
