# Quality Score Improvement

## What this skill does

Treats Quality Score as a diagnostic: each weak component points at a real user problem (irrelevant ad, weak page) worth fixing for its own sake.

## Inputs to collect

- Keyword-level Quality Score and component data
- Ad copy and landing pages for low-scoring themes
- Search term reports for those themes

## Workflow

1. **Segment the problem** - Pull keywords with QS under 6 and group by which component is below average. Fix components, not the blended number.
2. **Fix expected CTR** - Tighten ad groups so ads mirror queries, sharpen headline 1, and remove keywords whose intent doesn't belong in the group.
3. **Fix ad relevance** - One theme per ad group; if a keyword needs different copy, it needs its own ad group. Merge near-duplicates pulling volume down.
4. **Fix landing page experience** - Message match from ad to H1, page speed, mobile usability and content that actually covers the query topic.
5. **Remeasure fairly** - QS updates with impressions; judge on themes after meaningful volume, and confirm CPC/conversion effects - the point is cheaper, better traffic.

## Deliverable

- QS diagnosis by component and theme
- Ad group restructure list
- Landing page fix list tied to themes

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Share of spend on QS 7+ keywords | The health trend that matters |
| Average CPC trend on fixed themes | QS gains should show up in auction prices |
| Conversion rate on fixed themes | Relevance fixes usually lift both QS and CVR |

## Quality checklist

- [ ] No QS chasing via clickbait that hurts conversion
- [ ] Landing fixes improve the page for users, not just the score
- [ ] Component-level diagnosis recorded before changes

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Ad policy compliance: no misleading claims, no prohibited content, no trademark abuse. Ads must promise only what the landing page delivers.
- Never advertise results, prices or offers the business cannot honour today.
