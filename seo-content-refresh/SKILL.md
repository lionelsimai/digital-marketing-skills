# SEO Content Refresh

## What this skill does

Runs a systematic refresh cycle - identify decay, diagnose why, update substance - so the existing library keeps earning instead of rotting.

## Inputs to collect

- Search Console data: pages with falling clicks/positions over 6-12 months
- Content inventory with publish/update dates
- Current facts, pricing and product details for updates

## Workflow

1. **Find the decay** - List pages down 20%+ in clicks year-on-year or sliding from page 1. Separate true decay from seasonality and tracking changes.
2. **Diagnose before editing** - Classify each page: outdated facts, intent drift (SERP changed), stronger competitors, or cannibalisation. The fix differs by cause.
3. **Update substance, not dates** - Correct facts, add the missing sections the SERP now expects, improve examples and media. Never just change the publish date.
4. **Tighten internal support** - Add fresh internal links from newer content to refreshed pages, using the keyword map's owner assignments.
5. **Track the recovery** - Log changes with dates; review at 30/60 days against the pre-refresh baseline.

## Deliverable

- Decay list with diagnosis per page
- Refresh worklist with change log
- 30/60-day recovery tracking sheet

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Clicks recovered vs baseline | Per refreshed page at 60 days |
| Share of library refreshed per quarter | A steady cadence beats annual purges |
| Pages in decay at any time | Should shrink as the cycle matures |

## Quality checklist

- [ ] Diagnosis recorded before any edit
- [ ] URLs preserved unless a redirect plan exists
- [ ] Date changes reflect real content changes

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- White-hat only: no purchased links, link schemes, PBNs, keyword stuffing, cloaking or scraped/spun content. Earn coverage and links with assets worth citing.
