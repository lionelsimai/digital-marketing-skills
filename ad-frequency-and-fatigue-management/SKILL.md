# Ad Frequency and Fatigue Management

## What this skill does

Installs an early-warning system for fatigue - performance decay by frequency band - plus a rotation bench so refresh is a process, not a panic.

## Inputs to collect

- Platform frequency and performance data by campaign
- Creative inventory: live, in production, retired
- Audience sizes per campaign

## Workflow

1. **Find the fatigue curve** - Plot CTR/CVR by frequency band per campaign. Most accounts have a clear band where returns fall off a cliff; find yours, don't borrow averages.
2. **Set caps from the curve** - Set frequency caps at the decay point per funnel layer (prospecting stricter than remarketing). Review when audience size changes materially.
3. **Build the rotation bench** - Maintain at least 2 proven ads and 2 challengers per major ad set. Rotation means new angles, not new crops of the same image.
4. **Define refresh triggers** - Objective triggers: CTR down 20%+ from peak at equal frequency, CPA up a set band for a set window, negative feedback signals rising.
5. **Retire and learn** - Retire fatigued ads into a learnings log: angle, run length, peak metrics. The log is what makes the next creative better.

## Deliverable

- Fatigue curves and cap settings per layer
- Rotation bench tracker
- Creative learnings log

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Performance by frequency band | The core diagnostic, reviewed weekly |
| Creative lifespan | Median days a new ad stays above performance floor |
| Refresh cycle time | Days from trigger to replacement live |

## Quality checklist

- [ ] Caps derived from this account's data
- [ ] Refresh means new angles, not cosmetic variants only
- [ ] Retired ads logged with learnings

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Buy media the business can measure. If a placement cannot be tracked or brand-lift measured, size it as an experiment, not a pillar.
