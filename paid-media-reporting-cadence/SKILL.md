# Paid Media Reporting Cadence

## What this skill does

Replaces dashboard chaos with three disciplined loops, each answering a different question: is anything broken, what are we optimising, is the strategy working.

## Inputs to collect

- Channels and accounts in scope
- Stakeholders and their decisions (who acts on what)
- Data sources and their refresh reliability

## Workflow

1. **Daily health check (15 min)** - Spend pacing, disapprovals, tracking breaks, zero-impression campaigns. Exceptions only - no daily strategy debates.
2. **Weekly optimisation note** - One page: top movers, tests running with status, budget moves made with reasons, next week's planned changes. Written by the operator, not auto-generated.
3. **Monthly strategy review** - Marginal returns by channel, fatigue and creative state, incrementality learnings, and the reallocation proposal for next month.
4. **Fix the templates** - One template per loop, frozen for a quarter. Template churn destroys trend comparability.
5. **Archive decisions** - Store notes and reviews in one place. Six months of these is the best media training set a team owns.

## Deliverable

- Three reporting templates (daily, weekly, monthly)
- Cadence calendar with owners
- Decision archive structure

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Issues caught by daily check before stakeholders | The daily loop's reason to exist |
| Weekly note completion rate | Skipped weeks predict drifting accounts |
| Forecast actions completed from monthly reviews | Reporting that changes nothing gets cut |

## Quality checklist

- [ ] Each loop answers one question only
- [ ] Templates frozen per quarter
- [ ] Notes written by a human who owns the numbers

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Buy media the business can measure. If a placement cannot be tracked or brand-lift measured, size it as an experiment, not a pillar.
