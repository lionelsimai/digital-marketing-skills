# Programmatic Display Planning

## What this skill does

Builds a display plan where quality controls come before reach: inclusion lists, viewability thresholds and measurement that survives scrutiny.

## Inputs to collect

- Campaign goal (awareness, consideration, remarketing)
- Brand safety requirements and prohibited content categories
- Creative sizes and any rich media constraints

## Workflow

1. **Define quality floors** - Set viewability minimums, invalid-traffic tolerance and brand-safety tiers before any inventory is bought. Write them into the plan and the IO.
2. **Build inclusion-first inventory** - Start from curated publisher/app inclusion lists and private deals where relevant; open exchange only with verification and blocklists active.
3. **Layer targeting with consent** - Contextual first, then consented audience data. Document data sources; no shady third-party segments of unknown origin.
4. **Cap frequency with intent** - Set frequency by funnel stage (prospecting lower, remarketing considered) and monitor cross-device duplication where possible.
5. **Measure honestly** - Report viewable impressions, reach and brand-lift or assisted outcomes. Last-click claims for display are treated as fiction by default.

## Deliverable

- Display plan with quality floors and inventory approach
- Inclusion/blocklist starter set
- Measurement framework (viewability, IVT, lift)

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Viewability rate | Against the plan floor, by placement group |
| Invalid traffic rate | From the verification vendor, trended |
| Cost per reached target user | Deduped reach where measurable, not raw impressions |

## Quality checklist

- [ ] Verification (brand safety/IVT) active before first spend
- [ ] Data segments have documented, consented sources
- [ ] No made-for-advertising sites in inclusion lists

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Buy media the business can measure. If a placement cannot be tracked or brand-lift measured, size it as an experiment, not a pillar.
- Never buy inventory you cannot verify. If a deal forbids third-party verification, walk away.
