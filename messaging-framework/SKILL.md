# Messaging Framework

## What this skill does

Turns positioning into the working document copywriters, ad builders and sales actually use: what to say to whom, in what order, with what proof.

## Inputs to collect

- Positioning statement
- Personas with pains and objections
- Claims register with verified proof

## Workflow

1. **Set the hierarchy** - Master narrative (the story in 3 beats), then per-audience value propositions, then per-pain messages. Lower levels must inherit, never contradict, the level above.
2. **Build the matrix** - Rows: audience segments. Columns: primary pain, message, proof, CTA. One message per cell - if a cell needs three, the segment is too broad.
3. **Write in customer language** - Draft messages from verbatim phrases in research. Then translate features into outcomes: every feature sentence must answer 'which means you can...'.
4. **Pressure-test against competitors** - Swap test: replace your name with a competitor's in each message. If it still reads true, the message is generic - rewrite or retire it.
5. **Publish with usage rules** - Where each message is used (ads, pages, decks, emails), who may adapt it, and the review cadence when proof or products change.

## Deliverable

- Messaging framework document (hierarchy + matrix)
- Swap-test results with rewrites
- Usage rules and review cadence

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Message adoption across channels | Sampled audit of live assets per quarter |
| Swap-test pass rate | Share of messages that fail if a competitor's name is inserted - should be most of them |
| Conversion on assets rebuilt from the framework | Against their previous versions |

## Quality checklist

- [ ] Every message has proof attached
- [ ] No cell contains a claim the claims register doesn't support
- [ ] Framework fits how copy gets made, not just how strategy reads

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Brand claims obey the same proof rules as performance claims. Aspiration is fine; fabrication is not.
