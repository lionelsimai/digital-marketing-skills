# Pricing and Packaging Experiments

## What this skill does

Brings experiment discipline to the highest-leverage page in the business: test packaging and value metrics with the same rigour as headlines - and more care.

## Inputs to collect

- Current pricing, plan mix and revenue per account data
- Value metric candidates (what scales with customer value)
- Customer research on how buyers evaluate plans

## Workflow

1. **Start with packaging, not price points** - Test what's included, how plans are differentiated and which value metric meters usage before touching numbers. Packaging confusion is usually costlier than price level.
2. **Interview before experimenting** - 10-15 buyer conversations on plan evaluation, deal-breakers and the metric they find fair. Pricing experiments without qualitative grounding test the wrong things.
3. **Design the test cleanly** - New visitors see the test; existing customers are grandfathered and informed per policy - never silently re-priced. Define the read: conversion, plan mix, revenue per visitor, and 90-day cohort follow-up.
4. **Size for revenue, not clicks** - Pricing tests need revenue-per-visitor power, which takes longer. Set the duration honestly and resist early calls on noisy revenue data.
5. **Decide with the follow-up data** - Judge on conversion AND early retention/expansion of test cohorts. A price that wins signups and doubles churn is a loss wearing a costume.

## Deliverable

- Experiment design: packaging variants, audience rules, metrics
- Interview synthesis on plan evaluation
- Decision memo with cohort follow-up plan

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Revenue per visitor by variant | The primary read |
| Plan mix shift | Where demand actually wants to sit |
| 90-day retention/expansion of test cohorts | The verdict that outranks signup rate |

## Quality checklist

- [ ] Existing customers grandfathered and informed per policy
- [ ] Duration powered for revenue, stated upfront
- [ ] Decision waits for the cohort follow-up window

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Growth never overrides consent or honesty: no spam invites, no contact scraping for referral mechanics, no dark-pattern virality.
- Experiments on pricing and billing must be transparent to affected users - no silent price tests on existing customers' renewals.
- Never run covert personalised pricing on identifiable individuals, and never show different prices based on protected or sensitive characteristics.
