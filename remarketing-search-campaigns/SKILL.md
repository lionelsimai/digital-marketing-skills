# Remarketing Search Campaigns (RLSA)

## What this skill does

Captures the highest-intent paid search segment - people who already visited - with its own budget, copy and targets instead of blending it into prospecting.

## Inputs to collect

- Website audience lists (analytics/ads) with sizes and membership durations
- Visitor segments: product viewers, cart/lead starters, converters
- Offer for returning visitors (if any)

## Workflow

1. **Build intent tiers** - Tier by behaviour: converted (exclude or upsell), high-intent non-converters (viewed pricing/started form), content readers. Each tier gets different treatment.
2. **Set campaign structure** - Duplicate proven generic campaigns as RLSA versions with their own budgets and targets, or use audience observation first to size the opportunity before splitting.
3. **Adjust copy for returners** - Reference the relationship honestly ('still comparing?') and answer the objection that stopped them: price proof, guarantee, comparison content.
4. **Control overlap and exclusions** - Exclude converters from prospecting RLSA, set membership durations to the real sales cycle, and check audience sizes meet platform minimums.
5. **Judge on incrementality** - Compare RLSA CPA against generic, but also watch assisted effects. Set a holdout or pause test if stakeholders doubt the value.

## Deliverable

- Audience tier map with treatments
- RLSA campaign structure and copy set
- Exclusion and duration settings sheet

## Success metrics

| Metric | How to read it |
|--------|---------------|
| RLSA CPA vs generic CPA | Returners should convert cheaper; if not, the copy/offer is wrong |
| Conversion rate by visitor tier | Validates the tiering logic |
| Share of generic conversions touched by RLSA | Context for incrementality debates |

## Quality checklist

- [ ] Privacy: audiences built only from consented tracking; no sensitive-category targeting
- [ ] Converters excluded where they should be
- [ ] Audience sizes verified above platform minimums before launch

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Ad policy compliance: no misleading claims, no prohibited content, no trademark abuse. Ads must promise only what the landing page delivers.
- Never advertise results, prices or offers the business cannot honour today.
- Never build remarketing audiences on sensitive traits (health, financial hardship, personal characteristics) - prohibited and wrong.
