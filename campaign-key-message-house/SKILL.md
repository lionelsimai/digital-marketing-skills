# Campaign Key Message House

## What this skill does

One structure that keeps a campaign saying the same thing in a hundred assets: every ad, email and page traces to a pillar and a proof.

## Inputs to collect

- Campaign proposition and objectives
- Proof library and claims register
- Audiences and channels for the campaign

## Workflow

1. **Set the roof** - The single campaign proposition in one sentence - the same sentence the creative brief carries.
2. **Build 3 pillars** - Three supporting reasons that together make the roof believable. Each pillar gets: the message, the proof, and the asset types that will carry it.
3. **Lay the foundation** - The credibility base: brand credentials, guarantees, track record - the facts that let a stranger trust the pillars.
4. **Adapt by audience** - For each segment: which pillar leads, which proof variant, which CTA. Adaptation changes emphasis, never the facts.
5. **Police the house in production** - Every asset is checked against the house before release: does it prove a pillar, use approved proof, and stay off the banned-claims list?

## Deliverable

- Message house document (roof, pillars, proof, foundation)
- Per-audience adaptation table
- Asset QA check against the house

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Asset compliance rate | Sampled assets fully traceable to pillars/proof |
| Message recall in post-campaign survey | Can the audience repeat the roof? |
| Pillar performance split | Which pillar's assets carried results - feeds the next house |

## Quality checklist

- [ ] Roof is one sentence, pillars are exactly three
- [ ] Every pillar has proof in the register
- [ ] Banned/off-limits claims listed explicitly

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Brand claims obey the same proof rules as performance claims. Aspiration is fine; fabrication is not.
