# Lead Magnet Creation

## What this skill does

Designs a lead magnet as a product, not a PDF afterthought: it solves one painful micro-problem for the exact audience the offer serves.

## Inputs to collect

- Persona pains and the core offer it should feed
- Existing content/data that can be repurposed
- Delivery stack: landing page, email automation, file hosting

## Workflow

1. **Pick the micro-problem** - One specific, urgent problem the persona faces this week, that the core offer solves fully. The magnet solves the first step, brilliantly and completely.
2. **Choose the format by job** - Template/checklist for speed, calculator/assessment for personalisation, short guide for depth, swipe file for practitioners. Format follows the problem, not production convenience.
3. **Produce to a quality bar** - Designed, edited, and useful without the sales pitch. If it wouldn't be shared in a professional group, it isn't ready.
4. **Build the delivery chain** - Landing page (one promise, one form), instant delivery email, and the follow-up sequence it triggers. Test the whole chain with a real signup.
5. **Plan promotion** - Where it will be offered: site placements, content CTAs, ads, partners. A magnet without placements is a file on a drive.

## Deliverable

- Finished lead magnet asset
- Landing page + delivery email live and tested
- Promotion placement plan

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Visitor-to-lead conversion on the landing page | Benchmark against the previous asset; 25%+ is healthy for warm traffic |
| Lead-to-customer rate from this magnet | The quality test - downloads that never buy are a targeting failure |
| Cost per lead when promoted with ads | Compared to direct-offer campaigns |

## Quality checklist

- [ ] Magnet solves its stated problem completely
- [ ] Delivery tested end to end before promotion
- [ ] No gated content that is just a sales brochure

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Original or properly licensed content only. No plagiarism, no scraped articles, no AI-spun rewrites of competitors' work.
- Statistics and quotes must trace to a real source the reader can check.
- Personal data collected must match the promised exchange - no hidden consent, no pre-ticked boxes, easy unsubscribe from the first email.
