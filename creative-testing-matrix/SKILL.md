# Creative Testing Matrix

## What this skill does

Turns creative testing from random rotation into a curriculum: each round answers a question and the answers compound into a creative playbook.

## Inputs to collect

- Concept set with angle labels
- Channel/format constraints and production capacity
- Historical creative results and learnings log

## Workflow

1. **Define the learning agenda** - This round's questions in order: which angle, which hook style, which format, which proof type. One question per round; the matrix serves the agenda.
2. **Build the matrix** - Cells = angle x hook (or format). Assign each cell a budget sufficient for a readable signal at the channel's costs; underfunded cells get cut, not starved.
3. **Hold the constants** - Audience, offer, landing page and flight window stay fixed inside a round. Changing two things makes both unlearnable.
4. **Read by the agenda** - Report winners per question, with the effect size and the confidence honestly stated. Feed every result into the creative learnings log.
5. **Promote and iterate** - Winning angle graduates to scale campaigns; the next round tests a new question against it as control. Losers are retired with their learnings recorded.

## Deliverable

- Testing matrix with budgets and schedule
- Learning agenda for the quarter
- Results entries in the creative learnings log

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Cost per reliable learning | Total test spend / questions answered with confidence |
| Winner durability | How long promoted winners hold performance at scale |
| Angle knowledge coverage | Share of the angle grid with a tested verdict |

## Quality checklist

- [ ] Each round answers one named question
- [ ] Cells funded to readable signal or removed
- [ ] Constants held inside a round

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Brand claims obey the same proof rules as performance claims. Aspiration is fine; fabrication is not.
