# Testimonial and Proof Library

## What this skill does

Creates the single source of truth for social proof, so every channel uses approved, current, verifiable evidence instead of hunting old decks.

## Inputs to collect

- Existing testimonials, results and logos scattered across assets
- Happy-customer identification process (CS/sales signals)
- Legal/brand requirements for usage rights

## Workflow

1. **Set the collection workflow** - Trigger points (post-success, renewal, praise in support) route to a simple ask with a template: what we may quote, where, and the approval the customer gives in writing.
2. **Structure every entry** - Quote/result, person, role, company, permission scope and date, the claims it supports, and the source record for any number. If it isn't structured, it isn't in the library.
3. **Tag by use** - Tags: claim supported, audience, funnel stage, industry, format (quote, video, data point, logo). Retrieval takes under a minute or the library will be bypassed.
4. **Verify before first use** - Numbers cross-checked against source systems; quotes confirmed verbatim with the giver. The library's credibility is the asset - protect it absolutely.
5. **Refresh and retire** - Quarterly: re-confirm permissions for flagship proof, retire stale results, and chase the gaps (claims with no proof) as a collection target list.

## Deliverable

- Proof library with structured, permissioned entries
- Collection workflow and ask templates
- Gap list: claims needing proof, with owners

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Retrieval time for a proof request | Under a minute is the adoption threshold |
| Share of marketing claims backed by library proof | Audited per quarter |
| Flagship proof freshness | Top-20 proof items re-confirmed within 12 months |

## Quality checklist

- [ ] Written permission attached to every entry
- [ ] Numbers verified against source records at entry
- [ ] Retired proof actually removed from live assets

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Brand claims obey the same proof rules as performance claims. Aspiration is fine; fabrication is not.
- An entry without permission and verification is not proof - it's a liability. It does not enter the library.
