# On-Page SEO Optimization

## What this skill does

Takes one page from brief to publish-ready: aligned to search intent, structured for readers first, and complete against what top-ranking pages cover.

## Inputs to collect

- Target keyword cluster and its intent label
- Current page URL and its Search Console data
- Product/service facts and verified proof for claims

## Workflow

1. **Study the SERP** - Read the top 5 results. Note format (guide, tool, list, service page), common sections and what none of them answer well.
2. **Set the metadata** - Title tag with the primary term and a reason to click; meta description as ad copy; one H1 that matches intent.
3. **Build the content structure** - Headings that answer the searcher's sub-questions in order. Cover the topic's essential entities and facts; add the gap you found in the SERP.
4. **Handle media and links** - Descriptive file names and alt text for images that need it; 3-5 internal links to related owner pages with descriptive anchors.
5. **Final intent check** - Read the page as the searcher: does the first screen confirm this page answers the query? If not, rewrite the opening.

## Deliverable

- Optimised page (or redline) with metadata set
- Internal link additions list
- Coverage note: what this page now answers that rivals miss

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Position for the target cluster | Track the cluster, not one vanity keyword |
| CTR from Search Console | Metadata rewrites should lift CTR at equal position |
| Engagement: scroll and time | Intent match shows up as readers staying |

## Quality checklist

- [ ] No keyword density targets or stuffing anywhere
- [ ] Claims on the page are verifiable
- [ ] Page serves a human reader before any crawler

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- White-hat only: no purchased links, link schemes, PBNs, keyword stuffing, cloaking or scraped/spun content. Earn coverage and links with assets worth citing.
