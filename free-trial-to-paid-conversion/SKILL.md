# Free Trial to Paid Conversion

## What this skill does

Treats the trial as a guided path to a value moment and a fair decision - not a countdown ambush - and measures conversion by cohort quality, not just rate.

## Inputs to collect

- Trial funnel data: start, activation, usage depth, conversion, by cohort
- What retained paying customers did during their trials
- Trial terms: length, card-upfront policy, extension rules

## Workflow

1. **Segment trialists by activation** - Activated vs not, and by usage depth. Conversion problems are usually activation problems wearing a trench coat - fix order follows the data.
2. **Engineer the trial journey** - A day-by-day path: setup help, the value moment, proof of value (usage summary), team invitation where relevant. Emails and in-product prompts serve the same map.
3. **Use usage-triggered prompts** - Prompts fire on behaviour (hit a limit, completed a key action, went quiet for 3 days), each with help first and upgrade second. Quiet-user prompts offer help, not discounts, first.
4. **Design the ending honestly** - Clear end date shown from day one, reminders before it, a summary of value received, and a downgrade path that keeps the door open. No surprise charges - card policies stated plainly at signup.
5. **Judge cohorts, not just rate** - Converted cohort's 90-day retention and expansion vs previous cohorts. Conversion bought by pressure churns; conversion earned by value stays.

## Deliverable

- Trial journey map with behaviour triggers
- Prompt and email set per trigger
- Cohort quality tracking for converted trials

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Trial-to-paid conversion by activation segment | The segmentation that runs the programme |
| Time to value moment within trial | Compress it and conversion follows |
| 90-day retention of converted cohorts | The quality control on every conversion tactic |

## Quality checklist

- [ ] Trial terms and any card requirement stated plainly before signup
- [ ] End-of-trial reminders sent before any charge
- [ ] Discount prompts never the first response to inactivity

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Growth never overrides consent or honesty: no spam invites, no contact scraping for referral mechanics, no dark-pattern virality.
- Experiments on pricing and billing must be transparent to affected users - no silent price tests on existing customers' renewals.
- Never convert trials by obscuring the end date, hiding cancellation, or charging without the agreed reminder. Dark-pattern conversion is churn plus refunds plus reputation damage.
