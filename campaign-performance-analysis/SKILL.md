# Campaign Performance Analysis

## What this skill does

A post-campaign analysis that separates luck from skill: results against the pre-agreed goal, drivers evidenced, and learnings written for the next planner.

## Inputs to collect

- Campaign plan with goals and decision rules
- Platform + analytics + CRM results for the full attribution window
- Timeline of changes made during the flight

## Workflow

1. **Wait for the full window** - Analyse after the attribution/sales window closes, not at last click of the flight. Early reads systematically undervalue slow channels.
2. **Score against the plan** - Goal vs actual on the primary metric first, then guardrails, then efficiency. The plan's own words judge the campaign - not a benchmark chosen afterwards.
3. **Decompose the result** - By audience, creative angle, placement and week. Find the cells that carried the result and the cells that dragged it; averages hide both.
4. **Attribute causes carefully** - Cross-check with the change timeline and external factors (competitor moves, seasonality, PR). Label each cause confirmed, likely, or unknown.
5. **Write the next-campaign deltas** - Exactly what changes next time: keep, kill, scale, test. Filed with the analysis so the next planner inherits it.

## Deliverable

- Post-campaign analysis: goal scorecard, decomposition, causes
- Keep/kill/scale/test decisions
- Updated benchmark entries for the channel

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Goal attainment on primary metric | The campaign's verdict |
| Top-cell concentration | Share of results from the best audience/creative cells - informs next flight's focus |
| Learnings reused | Next campaign plans citing this analysis |

## Quality checklist

- [ ] Analysis waited for the full attribution window
- [ ] Causes labelled by confidence level
- [ ] Benchmarks updated, not cherry-picked

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Track only with consent where required: respect consent mode, PDPA/GDPR obligations and platform policies. No fingerprinting workarounds, no tracking people who said no.
- Report uncertainty honestly: modelled and sampled data labelled as such; never present platform attribution as ground truth.
