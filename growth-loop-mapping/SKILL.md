# Growth Loop Mapping

## What this skill does

Replaces funnel thinking with loop thinking for businesses that have one: how output from one cycle becomes input to the next, and where the loop leaks energy.

## Inputs to collect

- How new users/customers currently arrive, by mechanism
- What users create or generate that others see (content, invites, data, spend)
- Unit economics per cycle (cost to serve, revenue generated)

## Workflow

1. **Inventory candidate loops** - Content loop (users create what ranks), viral loop (users invite), economic loop (revenue funds acquisition that funds revenue), network loop (more users make it better). Most businesses have one real loop and several imaginary ones.
2. **Draw the strongest loop fully** - Every step from user action to new user, with the value captured and reinvested at each step. The step where value leaks out is marked in red.
3. **Quantify the cycle** - Per cycle: input cost, output (new users/revenue), cycle time. A loop you can't quantify is a hope with a diagram.
4. **Compare against paid acquisition** - Model loop output vs equivalent paid spend over 4 quarters. Loops usually lose early and win late - the plan should show the crossover honestly.
5. **Pick the investment** - The one loop to strengthen this year, the leak to fix first, and the metric that proves the loop is spinning faster.

## Deliverable

- Loop map with quantified cycle
- Loop vs paid comparison model
- Investment decision: loop, leak, proof metric

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Loop output per cycle | New activated users or revenue generated per turn |
| Cycle time trend | Loops compound on speed |
| Share of growth from the loop | Trended quarterly with honest attribution |

## Quality checklist

- [ ] Loop quantified or explicitly labelled unquantified
- [ ] Leak step identified with evidence
- [ ] Paid comparison uses real unit economics

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Growth never overrides consent or honesty: no spam invites, no contact scraping for referral mechanics, no dark-pattern virality.
- Experiments on pricing and billing must be transparent to affected users - no silent price tests on existing customers' renewals.
