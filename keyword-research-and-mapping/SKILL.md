# Keyword Research and Mapping

## What this skill does

Produces a keyword map the content team can execute: every important query has an owner page, an intent label and a priority.

## Inputs to collect

- Seed topics from products, services and customer language
- Search Console query data and any paid search converting terms
- Competitor domains for gap analysis

## Workflow

1. **Expand the seed list** - Pull queries from Search Console, keyword tools, competitor rankings, site search and customer verbatims. Keep the raw file; dedupe later.
2. **Label intent honestly** - Classify each cluster: transactional, commercial, informational, navigational. Intent decides page type - a blog post cannot do a service page's job.
3. **Score by value, not just volume** - Rank by revenue relevance x intent strength x ranking difficulty. Ten buying queries beat a thousand casual ones for most businesses.
4. **Map one cluster per page** - Assign each cluster a single owner URL (existing or planned). Flag cannibalisation where two pages chase the same cluster.
5. **Set the build order** - Sequence: fix cannibalisation, strengthen near-win pages (positions 4-15), then build new pages by score.

## Deliverable

- Keyword map: cluster, intent, owner URL, priority
- Cannibalisation list with merge/redirect decisions
- New page briefs list in build order

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Share of target clusters with an owner page | Coverage of the map over time |
| Clusters in top 10 | Trended monthly by intent type |
| Cannibalisation count | Should fall to zero after fixes |

## Quality checklist

- [ ] Intent labels checked against actual SERP results, not guesses
- [ ] Every money keyword has exactly one owner page
- [ ] Volume never used as the only ranking factor

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- White-hat only: no purchased links, link schemes, PBNs, keyword stuffing, cloaking or scraped/spun content. Earn coverage and links with assets worth citing.
