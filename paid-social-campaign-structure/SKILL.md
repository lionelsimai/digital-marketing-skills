# Paid Social Campaign Structure

## What this skill does

Builds paid social campaigns that give the algorithm clean signal: consolidated where it helps, separated where economics differ, with creative as the targeting lever.

## Inputs to collect

- Offer and conversion event with values
- Audience assets: site visitors, customer lists, engagement audiences
- Creative set: formats per placement, with hooks documented

## Workflow

1. **Pick the true objective** - Optimise for the deepest event with sufficient volume (purchase/qualified lead); use shallower events only as a documented compromise with a volume problem.
2. **Layer audiences deliberately** - Core prospecting (broad or interest/lookalike), warm remarketing, existing customers (excluded or upsell). Each layer its own campaign and budget.
3. **Design ad sets around creative angles** - Group ads by angle (pain, proof, offer, comparison) so results teach you which message works, not just which image.
4. **Set budget mechanics** - Campaign-level vs ad-set budgets chosen by test design; learning thresholds budgeted for (enough spend per ad set to exit learning).
5. **Launch with a test matrix** - Document what's being tested (angle, hook, format), the spend each cell gets, and the decision date. No silent always-on tweaking.

## Deliverable

- Campaign tree: campaigns, layers, ad sets, ads
- Creative angle matrix with test assignments
- Budget and learning-threshold plan

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Cost per result by layer | Prospecting vs remarketing judged separately |
| Creative angle win rate | Which messages earn scale across audiences |
| Frequency in prospecting | Rising frequency with flat results signals fatigue or a too-small audience |

## Quality checklist

- [ ] Converters excluded from prospecting
- [ ] Event firing verified in the platform's test tools before launch
- [ ] Sensitive targeting categories avoided (no discriminatory inclusions/exclusions)

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Buy media the business can measure. If a placement cannot be tracked or brand-lift measured, size it as an experiment, not a pillar.
- Follow each platform's ad policies on personal attributes, housing/employment/credit and before-after imagery. When in doubt, the policy page decides, not the deadline.
