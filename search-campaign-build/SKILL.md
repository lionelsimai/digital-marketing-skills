# Search Campaign Build

## What this skill does

A complete, checked campaign build - the difference between a campaign that launches clean and one that burns budget in week one.

## Inputs to collect

- Keyword cluster with intent labels
- Landing page URL and its offer
- Daily budget, target CPA/ROAS and geo/language scope

## Workflow

1. **Confirm the landing page first** - Check the page loads fast, matches the keyword intent, and carries the conversion action. No page, no campaign - fix the page first.
2. **Build keyword sets** - Add keywords by theme with the match strategy for this campaign; seed the negative list from day one (irrelevant intents, job-seekers, free-seekers where appropriate).
3. **Write responsive search ads** - Pin the promise to position 1-2, fill headlines with distinct benefits/proof/CTA angles, paths that mirror the query theme. No duplicate filler headlines.
4. **Add assets (extensions)** - Sitelinks to real sub-pages, callouts from verified facts, structured snippets, call/lead assets only where staffed to respond.
5. **Run the launch QA** - Budget, bids, geo presence settings ('presence' not 'interest' for local), ad schedule, tracking template and conversion actions all checked by a second pair of eyes before enable.

## Deliverable

- Built campaign in a pre-launch (paused) state
- Launch QA checklist, signed off
- Week-1 monitoring plan: search terms review dates and kill thresholds

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Week-1 search term relevance | Share of spend on terms matching the intended theme; target 90%+ |
| CTR vs account benchmark | Early signal of message match |
| Cost per conversion at day 14 | Judge against target only once volume is statistically meaningful |

## Quality checklist

- [ ] Negative seed list applied before enable
- [ ] Geo targeting set to presence where intent is local
- [ ] Conversion actions tested end to end

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Ad policy compliance: no misleading claims, no prohibited content, no trademark abuse. Ads must promise only what the landing page delivers.
- Never advertise results, prices or offers the business cannot honour today.
