# Funnel Architecture Design

## What this skill does

Maps a prospect's path from first touch to customer as a set of designed stages, so gaps (traffic with no capture, leads with no follow-up) become visible and fixable.

## Inputs to collect

- The core offer and its price point
- Current lead sources and any existing lead magnet or entry offer
- Sales process: who follows up, how fast, and in what system

## Workflow

1. **Define the stages** - Use five working stages: Attract, Capture, Nurture, Convert, Ascend. Write the prospect's question at each stage in their words.
2. **Assign one offer per stage** - Entry offer for capture (guide, assessment, webinar), core offer for convert, and one ascension offer. Each offer must make the next stage easier to say yes to.
3. **Specify the assets** - List the page, email sequence and ad angle each stage needs. Mark what exists, what is broken, and what is missing.
4. **Set stage metrics and owners** - One primary metric per stage (e.g. landing conversion rate at Capture, speed-to-lead at Convert) and a named owner for each.
5. **Find the constraint** - Multiply the stage conversion rates. The weakest stage is the build priority; document it as the first project, not an afterthought.

## Deliverable

- Funnel map: stages, offers, assets, owners
- Stage metric sheet with target rates
- Build/fix list ordered by constraint stage first

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Stage conversion rates | The product of all stages is total funnel yield; improve the lowest first |
| Cost per stage transition | Shows where paid traffic leaks value |
| Speed to first follow-up | Under 5 minutes for hot leads is the working standard |

## Quality checklist

- [ ] Every stage has exactly one offer and one owner
- [ ] No stage depends on an asset nobody has agreed to build
- [ ] Follow-up path exists before traffic is planned

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Strategy before channels: never recommend a channel or budget split without the offer, audience and unit economics in hand.
