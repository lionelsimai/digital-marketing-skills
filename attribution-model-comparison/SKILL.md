# Attribution Model Comparison

## What this skill does

Shows stakeholders how the story changes between last-click, first-click, data-driven and blended views - and builds decisions robust to that uncertainty.

## Inputs to collect

- Conversion and touchpoint data for a full sales cycle
- Channel spend for the same period
- The decisions attribution is meant to inform

## Workflow

1. **Run the same period through each model** - Last-click, first-click, position-based and platform data-driven, side by side per channel. Same window, same conversions - only the credit rule changes.
2. **Highlight the swing channels** - Channels whose value flips between models (usually video, social, content) get flagged: these are where budget fights come from, and where incrementality testing is worth its cost.
3. **Triangulate with non-model evidence** - Post-purchase surveys ('how did you hear about us'), branded search trends, and any holdout/geo results. Models are lenses; evidence is plural.
4. **Adopt a decision view** - Agree the house view for routine decisions (often blended/data-driven with a last-click sanity column) and the review rhythm for revisiting it.
5. **Document the known blind spots** - Offline, word-of-mouth, dark social, view-through inflation - written into the report so nobody mistakes the model for reality.

## Deliverable

- Model comparison table per channel
- Swing-channel list with incrementality recommendations
- Adopted decision view + blind-spot register

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Budget decisions changed by triangulation | The comparison earning its keep |
| Survey-vs-model agreement rate | A rough external validity check |
| Stakeholder disputes over credit | Should decline once the house view is adopted |

## Quality checklist

- [ ] Same data window across all models
- [ ] Blind spots documented in the report itself
- [ ] No channel judged by a single model's output

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Track only with consent where required: respect consent mode, PDPA/GDPR obligations and platform policies. No fingerprinting workarounds, no tracking people who said no.
- Report uncertainty honestly: modelled and sampled data labelled as such; never present platform attribution as ground truth.
