# Media Budget Scenario Modelling

## What this skill does

Gives decision-makers an honest menu: what each budget level likely buys, where diminishing returns bite, and what must be true for the aggressive case.

## Inputs to collect

- Channel benchmarks: CPM/CPC ranges, conversion rates
- Auction headroom data (impression share, reach saturation)
- Business capacity limits (sales, stock, onboarding)

## Workflow

1. **Build the response curves** - Estimate how each channel's cost per outcome degrades as spend rises, using impression share lost to rank/budget and historical scaling data.
2. **Draft three scenarios** - Conservative (proven lines only), base (plus best tests), aggressive (new channels/audiences). Each with spend, expected outcomes and ranges - not point estimates.
3. **Overlay capacity** - Check scenarios against fulfilment: can sales call the leads, is stock there, can onboarding absorb the customers? Cap the recommendation at capacity.
4. **Name the assumptions** - List the 3-5 assumptions each scenario depends on and how you'll know within 2 weeks if one is wrong.
5. **Recommend with a trigger plan** - Recommend one scenario plus the evidence that would justify stepping up or down mid-flight.

## Deliverable

- Scenario table with ranges and assumptions
- Response-curve notes per channel
- Step-up/step-down triggers for the flight

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Scenario accuracy at flight end | Which scenario the actuals landed in - and why |
| Marginal cost at scale | Compare modelled vs realised degradation |
| Capacity breach incidents | Times media outran operations (target: none) |

## Quality checklist

- [ ] Outcomes given as ranges with assumptions attached
- [ ] Capacity checked before recommending the aggressive case
- [ ] Diminishing returns shown, not hidden

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Buy media the business can measure. If a placement cannot be tracked or brand-lift measured, size it as an experiment, not a pillar.
