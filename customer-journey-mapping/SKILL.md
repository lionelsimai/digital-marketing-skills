# Customer Journey Mapping

## What this skill does

Creates a working journey map that connects marketing touchpoints to the moments where prospects stall, so budget goes to the stage where people actually drop.

## Inputs to collect

- Analytics: top entry pages, assisted conversions, time to purchase
- Sales/CS notes on common questions and stalls
- List of current touchpoints: ads, emails, pages, calls, events

## Workflow

1. **Fix the stages and timeframes** - Define stages (Aware, Consider, Decide, Onboard, Advocate) and the typical days spent in each, from data - not from the org chart.
2. **Plot real touchpoints** - Place every actual touchpoint on the map with its owner and its job. Mark zombie touchpoints nobody maintains.
3. **Annotate emotion and questions** - For each stage, write the prospect's top question and dominant emotion (curious, anxious, comparing). This drives content topics.
4. **Locate the drop-offs** - Use funnel and cohort data to mark where the biggest share of prospects exit. Separate 'never came back' from 'came back later'.
5. **Assign fixes per stage** - One fix per weak stage with owner and measure: content to answer the question, proof to cut the anxiety, or follow-up to catch the stall.

## Deliverable

- Journey map with stages, touchpoints, questions, emotions
- Drop-off report with the two worst stages evidenced
- Fix list: one intervention per weak stage, with owner

## Success metrics

| Metric | How to read it |
|--------|---------------|
| Stage-to-stage progression rate | The map's core output; re-measure after each fix |
| Median days per stage | Long stalls signal missing content or follow-up |
| Assisted conversion share | Shows which touchpoints quietly do the persuading |

## Quality checklist

- [ ] Stages defined by buyer behaviour, not internal departments
- [ ] Every touchpoint has an owner
- [ ] Drop-off claims cite a data source

## Guardrails

- Claims discipline: use only proof the user supplies or verifies. Never invent clients, results, rankings, or testimonials.
- Privacy and consent: collect and use personal data only with a lawful basis and consent where required. Respect PDPA (Singapore) and GDPR; honour unsubscribes and opt-outs immediately.
- Platform policy: follow each ad and search platform's current policies. When a rule changes often, flag it for a human to re-check before launch.
- Strategy before channels: never recommend a channel or budget split without the offer, audience and unit economics in hand.
